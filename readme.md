# Kwork-Parser

Асинхронный парсер новых заказов с kwork.ru  
Уведомляет о них в заданный Telegram-канал.

Telegram-канал: https://t.me/kworkneworders

В уведомление попадают название со ссылкой на заказ, описание, вилка бюджета,
количество уже поданных предложений и время до закрытия набора.

## Готовимся к запуску
```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
Укажите в .env токен бота & ID канала, куда будут отправляться уведомления, ID
категорий, которые нужно парсить с kwork. Их можно найти в ссылке - https://kwork.ru/projects?fc=39.
Здесь 39 - ID категории.

## Запуск (из корня проекта)
```bash
python main.py
```
При старте парсер запоминает текущие заказы и ничего не отправляет — уведомления
приходят только о заказах, появившихся после запуска. Остановка по Ctrl+C.

## Структура

| Файл | Отвечает за |
|---|---|
| `main.py` | точка входа: конфиг, логи, запуск приложения |
| `src/app.py` | `Application` — владеет сессией и ботом, `CategoryWatcher` — цикл опроса одной категории |
| `src/parser.py` | `KworkParser` — запрос к kwork и отбор новых заказов |
| `src/models.py` | `Order` — модель заказа и формирование текста уведомления |
| `src/telegram_bot.py` | `TelegramBot` — отправка сообщений |
| `src/configuration.py` | `Settings` — чтение .env |

Один `KworkParser` создаётся на каждую категорию из `KWORK_CATEGORIES` и хранит
свой последний виденный id заказа, поэтому категории не мешают друг другу.
